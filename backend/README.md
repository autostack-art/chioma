# Chioma Backend

NestJS API for the Chioma housing protocol.

> **Setup:** Local setup for the whole stack lives in the root [Quickstart](../README.md#quickstart-clone--running-full-stack). Contribution conventions are in [CONTRIBUTING.md](CONTRIBUTING.md).

Common commands (from `backend/`):

```bash
pnpm run start:dev       # API on http://localhost:3000/api, docs at /api/docs
pnpm run migration:run   # apply database migrations
pnpm run seed:all        # seed default users
make ci                  # run the CI pipeline locally
```
